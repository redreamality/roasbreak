Returns, Refunds, and Discounts

A discount lowers revenue on every promoted order. A return can reverse revenue, add logistics cost, and sometimes recover inventory. Combining them hides the action available.

Expected return loss

Model the loss, not only the return rate.

A useful expected-return allowance includes refunded revenue, reverse logistics, non-recoverable product cost, and non-refundable transaction fees, then subtracts recoverable inventory value and any return fee retained.

ComponentEffect
Refunded product revenueReduces net revenue
Reverse shipping and inspectionAdds variable cost
Unsellable productLoses inventory value
Restockable productRecovers part of inventory value
Non-refunded payment feeRemains a cost after refund

Discounts are different

A 10% discount applies before the order is fulfilled and often changes product mix, conversion, and return behavior. Evaluate it through the promotional order value and calculate the additional volume required to replace lost contribution.

Use mature order cohorts

Recent orders have not had time to return. Calculate allowances from cohorts old enough to pass the normal return window, and segment materially different products or regions.
