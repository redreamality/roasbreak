# 条件型内容与数据能力评估

> 评估日期：2026-08-21  
> 范围：研究清单 `CNT-016` 至 `CNT-022`、Backlog `P2-001` 至 `P2-006`  
> 结论：完成前置条件评估；当前没有任何条目满足启动条件。

## 评估原则

- “已评估”不等于“已实现”。本文件记录的是启动或暂缓决策。
- 没有 Search Console、站内行为或用户问题证据时，不用关键词直觉替代需求验证。
- 没有授权数据、稳定输入模型或持续维护责任人时，不创建案例、benchmark、区域站或平台连接。
- 每次重新评估必须引用可复核的数据窗口、事件定义、负责人和日期。

## CNT-016 至 CNT-018 排序决策

`CNT-016` Marketplace fees、`CNT-017` Average vs marginal ROAS 和 `CNT-018` Currency/tax/duty 均保持候选，不指定先后顺序。

重新排序至少需要下列一种证据，并使用连续 28 天以上的同口径窗口：

1. Search Console 查询或页面数据能映射到候选主题，且记录 clicks、impressions、CTR 与 position。
2. 非敏感站内事件能显示相关指南到工具的路径、计算完成或复制/分享行为。
3. 可复核的用户问题记录达到重复出现，而不是单一内部设想。

满足后按“问题频次、进入工具的意图强度、现有页面是否已覆盖、来源维护成本”排序。当前决策是 **不启动**，而不是三项并列优先。

## 重新评估记录要求

重新打开任一条目时，在本文件追加一条记录，至少包含：

- 评估日期、负责人和观察窗口；
- 使用的数据源及权限边界；
- 指标定义、样本量和已知缺口；
- `start`、`remain deferred` 或 `reject` 决策；
- 对应 issue、实现范围和下一次复核日期。

在这些字段齐全之前，研究清单中的条件型任务保持“前置条件已评估、实现未启动”。
